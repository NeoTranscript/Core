How to use the full flow:

1. Run npm run issuer in terminal to generate real JSON credentials
2. Open Issuer Demo → Issue a credential
3. Copy JSON or use "Load Generated" buttons in Verifier

All demos support both college transcripts (with courses) and high school diplomas.
