# Contributing to NeoTranscript

Thank you for considering contributing to NeoTranscript!

## Ways to Contribute

- **Feedback & Ideas**: Open a Discussion or comment on existing ones
- **Bug Reports & Feature Requests**: Open an Issue
- **Code Contributions**: Submit Pull Requests
- **Testing**: Try the demos and report issues
- **Outreach**: Help spread the word to colleges and high schools

## Development Setup

1. Clone the repository
2. Explore the `examples/` folder to try the live demos
3. Review `WHITEPAPER.md` and `MVP-SPEC.md` for project direction
4. Check the [Project Board](https://github.com/orgs/neotranscript/projects) for current tasks

## Pull Request Guidelines

- Keep changes focused and small
- Update documentation when relevant
- Test the demos after making changes
- Reference any related Issues or Discussions

## Code of Conduct

Please follow our [Code of Conduct](CODE_OF_CONDUCT.md). Be respectful, inclusive, and constructive.

## Questions?

Join the [Discussions](https://github.com/neotranscript/Core/discussions) or open an Issue.

We appreciate every contribution — whether it's code, feedback, or just sharing the project!
